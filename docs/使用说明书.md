# 使用指南

[返回首页](../README.md) · [多窗口阅读](多窗口阅读.md) · [开发指南](开发指南.md)

本指南对应当前主分支（v1.4.4），包含 Windows 安装与旧版迁移、应用内更新、记忆管理、资料存放、跨文件夹标签、PDF 整理，以及跨文件问答与后台生成。可下载版本以 [Releases](https://github.com/975952/prt/releases/latest) 为准。

## 第一次使用

1. 下载并运行 `prt-setup.exe`，按向导为当前 Windows 账户安装；无需管理员权限。完成后从开始菜单或桌面快捷方式打开 prt。
2. 拖入 PDF，或在左侧点击导入。安装版的论文库在系统“文档”目录下的 `prt\papers`。
3. 需要 AI 时，打开右上角设置，在模型设置中填写接口地址、模型名和 API Key，再保存并测试连接。

也可以下载免安装的 `prt.exe`，放到可写文件夹后运行；便携版继续把 `papers/` 和 `data/` 保存在程序旁。不要直接在压缩包内运行。两种版本使用同样的阅读功能，存储位置不同。

支持 Windows 10/11 x64。若提示缺少 WebView2，请安装 [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 后重开。不使用 AI 时也能阅读、搜索和记笔记。

## 界面与回答语言

首次使用默认显示 English。在 **Settings → Language / 设置 → 语言** 中选择简体中文或 English，再点击应用。切换前会保存当前会话、草稿和阅读位置；有未保存的设置或笔记时先完成编辑，生成中先停止。其他窗口会提示应用新语言，不会被强行刷新。

回答语言可选择跟随界面、简体中文或 English，影响新的 AI 回答；当前问题里明确指定的语言优先。译文输入框中的目标语言独立保存，不随界面切换。已有对话、笔记、文件名和论文原文不会被改写。[English quick start](quick-start.en.md)。

## 打开与管理论文

可以直接拖入整个文件夹，递归导入 PDF、PPT、PPTX 并保留目录结构。拖到书架或阅读侧栏的文件夹行即可指定目标；同名目录自动追加编号。隐藏名称、系统杂项和不含可导入文件的空目录会跳过。导入后自动展开目标的父目录并刷新文件树，让嵌套位置立即可见。

导入后，右下角任务面板持续显示“等待中 / 转换中 / 已完成 / 失败”。转换时可以继续添加，后续文件自动排队；仍在队列中的同一文件不会重复加入。成功后可点击“打开 PDF”，失败项可重试，结果保留到点击“清除已结束”。排队时间不计入两分钟转换时限。

**PPT 转 PDF：** 点击“打开 PDF / PPT”选择 `.ppt`、`.pptx`，或直接拖入文件；也支持多选、拖入目标文件夹及导入文件夹中的演示文稿。需要 Windows 上已安装并完成首次启动设置的 Microsoft PowerPoint。转换在本机进行，单文件上限 256MB，最长等待约两分钟。成功后 PDF 加入书架，单文件导入会直接打开；原始 PPT 不会修改，书架只保存转换后的 PDF。同名 PDF 自动追加序号，不覆盖已有文件。动画、音视频变为静态页面；加密或损坏的文稿可能无法转换。

Library 左侧可切换全部论文、最近阅读、未读和文件夹；右侧搜索框按标题、文件名或目录筛选。点击文件开始阅读；阅读区左侧可以筛选文件、创建文件夹、调整顺序和移动文件。多个 PDF 可同时保留在标签栏，切换时保留各自的阅读位置。

**管理文件夹（主分支新增）：** 点击 Library“文件夹”标题旁的 **+** 新建根目录文件夹；点击某个文件夹旁的 **…** 或右键，可新建子文件夹、重命名、移动到其他目录，或选择“删除文件夹（保留论文）”。名称在侧栏内编辑，Enter 保存，Esc 取消。重命名和移动会同步已打开标签及阅读位置的文件路径。

删除文件夹需要一次确认。程序先逐篇将 PDF 移到根目录，保持原文件名；同名冲突或移动失败时停止，未移动文件保留在原目录，已完成的移动保留。只有整个目录树不含任何文件或链接时才移除空目录；隐藏文件、非 PDF 文件等资料也会阻止删除。点击取消立即结束，不会接着询问是否彻底删除。

标签属于当前窗口的整个工作区，可以同时打开不同文件夹的论文。跨文件夹切换不会关闭其他标签，刷新后恢复仍存在的文件及原顺序；点击某个标签的关闭按钮只关闭该项。左栏选择文件夹会在首页浏览该目录，点开 PDF 后才切换阅读内容与会话归属。

顶栏 Library 和 Alina 是临时打开的界面：再次点击当前界面的按钮会回到最近阅读的论文，恢复页码、缩放和页内位置。两个界面之间切换也保留阅读位置；没有打开的标签时，可从保存的阅读记录恢复现存论文。未发送草稿按原会话保留，后台生成继续更新；没有阅读记录时留在当前界面。

### 批量整理 PDF（主分支新增）

打开程序默认进入 Library，原有标签和阅读记录仍保留。可在 **设置 → 阅读与问答 → 启动页面** 改为“继续上次阅读”或“智能体起始页”，自动保存，下次启动生效。直接打开指定 PDF 时优先进入该论文。

Library 首页和智能体主界面都有显式的“打开上次阅读区”按钮；本次已经打开过论文后显示“回到阅读区”，恢复当前论文与阅读位置。没有可用阅读记录时按钮置灰。智能体新对话入口统一位于侧栏，收起侧栏时显示气泡内加号图标；主内容区单独保留返回阅读按钮，不再显示重复的会话切换横条；“继续上次会话”用于恢复聊天，与返回阅读区分开。

Library 左侧导航可以拖动右边缘调整宽度，并记住调整结果。双击边缘恢复默认；聚焦分隔线后，左右方向键微调。窄窗口自动使用横向导航，不会覆盖保存的侧栏宽度。

阅读区再次点击当前高亮的侧栏图标会收起该侧栏并取消高亮，面板内部不再提供重复的关闭按钮。深色模式下 Library 与 Alina 使用一致的黑色背景。

模型设置有修改时点击“保存并测试”会保存并立即测试连接；没有修改时直接关闭设置。点击弹窗外部直接关闭，未保存的草稿不保留。

在 Library 点击 **整理 PDF / Organize PDFs**，先查看待整理清单。默认列出全部论文，便于重新整理已有的零散目录，也可切换为根目录未归类文件；每页显示 40 篇，支持搜索、勾选和修改目标文件夹。打开清单本身不会调用模型或移动文件。

点击 **开始分类**，AI 先按文件名和所在目录判断，合理分类优先保持原样，只整理需要调整的内容，相近内容放入同一类；所有分类都是一层文件夹，不再提供嵌套层级。可展开“分类偏好”填写补充要求。预览按类别聚合显示，同类论文放在一起。

此操作使用设置中的模型，先发送文件名与所在目录。名字不足以判断的文件才读取第一页：有可用文字时将文字加入统一分类；扫描页或文字仍无法判断时发送第一页图片。看图需要配置的模型支持图片；无法读取或仍不明确的文件保留待确认，不会擅自移动。

展开“分类方案”可查看每个目录包含的论文数，统计覆盖当前筛选范围的全部分页。在某个分类旁输入新名称并点击 **改名 / 合并**，即可批量修改这一分类的目标；输入另一个分类的名称会将两组并入同一目标。此时只修改预览，文件和磁盘目录尚未改变。

可以逐篇修改目标，或整类改名、合并。目标只接受单层名称，例如 `线性代数`，不接受 `数学/线性代数`。无法确定类别的文件不会自动勾选，可手动指定。

点击 **重新分类**会生成全新方案，覆盖之前所有建议、手动调整和勾选。已经移动过的文件也可以直接重新分类，确认后按新方案替换旧分类、清理旧空目录。失败、超时或停止时保留本次已完成的建议；再次运行会重新生成，不与旧方案累积。分类结果不写入聊天历史。

检查清单后点击 **移动选中的文件**。整理保留原文件名、论文笔记、会话和阅读进度，并更新当前论文与标签路径；已有文件夹会话仍保留在原归属。同名目标会报告冲突并保留两份文件，可修改目标后重试失败项。关闭预览不会移动文件；执行中的停止只影响后续项，已完成的移动保留。

如果文件正在被生成任务使用，请等待完成或停止任务后重试。移动大 PDF 后，继续阅读会从新位置重新加载并恢复阅读位置。

首页可用 `Ctrl+加号` / `Ctrl+减号` 整体缩放（70%–160%），`Ctrl+0` 恢复默认的 140%，缩放比例自动保存。数字文件名（如 `1706.03762.pdf`）会在后台从 PDF 元数据或首页文字提取标题，以“编号 · 论文标题”显示并参与搜索，不改动原文件。扫描件或无法可靠识别标题的文件保留编号。

需要并排对照时，右键标签选择在新窗口打开，或将标签拖出标签栏；完整操作见 [多窗口阅读](多窗口阅读.md)。

应用分类时会先保存原位置，再移动选中的论文并清理旧空分类目录。只清理实际移动文件后留下的旧空目录；不相关的空目录保持原样。包含其他文件、未移动论文的目录会保留，分类目标及其父目录不会被清理。

在 **设置 → PDF 整理 → 回退最近一次整理** 可恢复原来的论文位置和被清理的旧目录，并移除本次新建且已空的分类目录。保留最近 10 次整理，按从新到旧的顺序回退；重启后记录仍在。中断或回退失败可重试，同名冲突及大小或修改时间发生变化的文件不会被覆盖。旧版本没有记录整理前的位置，无法追溯回退。

删除论文和清空会话是不同操作。回退整理只恢复目录及文件位置，不恢复已删除或被外部修改的 PDF。

## 阅读与定位

顶栏有两个独立模式：**全屏 / F11** 保留原来的连续阅读布局；**翻书** 进入新的沉浸双页模式，铺满屏幕，每次只显示两页，纸张不再使用圆角卡片外框。点击屏幕左半边翻到上一组，右半边翻到下一组；方向键、PageUp/PageDown 和底部页码也可操作。拖动选择文字不会翻页。页面固定适配屏幕，工具栏隐藏时不会改变大小；鼠标靠近顶部或底部可显示工具栏，顶部“退出翻书”返回原阅读布局与最后阅读页。

翻书模式使用本地内置的仿真折页动画，可在设置中关闭动效。顶部“翻译”“问答”打开可拖动的浮动卡片。问答保留新对话、历史、截图、停止生成与草稿；关闭卡片后生成仍继续。翻译卡片提供原文对照、目标语言、截图翻译、复制、存笔记、重新翻译、停止和删除。译文按文档自动保存，可从“翻译记录”恢复，关闭卡片或重启不会清空记录。

进入翻书时会检测当前页的实际宽高（包含页面旋转）：宽高比达到 1.2 的横向页面按幻灯片放映，适用于常见的 4:3、16:9 课件。每次完整居中显示一页，等比例适配窗口，切页不使用折页动画；工具栏和浮动卡片沿用原有翻书模式，鼠标靠近顶部或底部显示工具栏、移开后隐藏，不额外预留空白或改变页面大小。支持左右/上下方向键、PageUp/PageDown、空格前进、Shift+空格后退、Home/End 跳到首尾页，以及滚轮、底部按钮和页码跳转。同一次翻书期间保持所选布局，退出后恢复原来的缩放与单双页设置。

阅读区文件侧栏只保留搜索、导入按钮和文件列表，仍支持拖入 PDF。当前会话标题只作名称显示，新对话与历史通过各自入口打开。

- **页码：** 底栏输入页码并按 Enter 跳转；两侧按钮前后翻页。
- **缩放：** 拖动缩放滑块，或点击 **Fit width / 适应宽度**。纸面贴合阅读区可用宽度，两侧保留少量边距；开关侧栏或调整窗口时继续贴合。双页模式保留两页之间的间隔，PDF 文件自身的页边距不变。
- **双页：** 底栏双页按钮切换并排阅读，翻页按一行两页前进。
- **搜索：** 点击放大镜或按 `Ctrl+F`，输入关键词，从结果跳回原文。
- **目录与引用：** 点击目录、回答中的页码或可定位原文引用跳转，再用返回原位置继续阅读。
- **笔记：** 选中文字后添加笔记，左侧笔记列表可回到对应位置。

引用卡片和参考文献列表中的“浏览器搜索论文”会直接打开默认浏览器，使用 Bing 搜索该文献。书架内已关联的论文仍可直接打开；外部搜索结果由浏览器显示。

## 翻译

在正文选中文字，点击翻译，或按 `T`。译文显示在右侧，可展开原文对照，并从定位入口回到论文。

右侧栏收起时，译文使用浮动卡片。拖动卡片标题栏可移动，拖动右下角可同时调整宽高；也可聚焦右下角手柄后用方向键微调。大小自动保存，长译文在卡片内部滚动。

连续选择不同段落可以分别翻译，无需等待前一条完成。译文在侧栏按发起顺序排列，最多同时生成三条，超出的任务排队处理。浮窗右上角的关闭按钮只收起卡片，已有任务继续在侧栏生成；再次选择后显示新一条，旧请求不会覆盖它。要取消并删除某一条，请使用该条译文的垃圾桶按钮。

也可以切到“译文”，在底部输入框粘贴原文。输入框左下角的“译成”选择中文或 English，按 Enter 发送，Shift+Enter 换行。

图表和扫描页无法划词时，使用截图按钮或 `R` 框选，确认截图后发送。拖到阅读区边缘可继续滚动形成长截图。图像翻译需要支持图像的模型。

多段文字可以合并翻译；多张截图可作为一批处理。失败或停止后，可重试未完成内容。已有译文下方的“重新翻译”会跳过缓存，沿用这条译文的目标语言。

点击每条译文右上角的垃圾桶即可直接删除，不弹出确认框。历史、截图、失败和未完成的译文都可单独删除；删除正在生成的结果会取消该条请求，批次中的其他项继续处理。删除会保存并同步到同一论文的其他窗口，不影响其他译文或问答。

## 问答与会话

切到“问答”，输入问题并发送。可以直接问当前论文，也可以先选中文字加入问答，或附上截图说明要讨论的图表。

普通追问会结合当前上下文；需要查证时，可以明确要求“查原文”“读第 3 页”或“检索全文”。AI 会按任务获取材料。联网检索需要可用的网络及对应服务。

默认按论文分别管理会话，历史默认按时间排列。可在 **设置 → 会话** 中选择按论文独立、按文件夹共享或全局共享，并调整打开时继续、新建或选择会话的行为。历史入口可以切换、重命名和管理会话。

返回工作区中已打开的论文或文件夹时，会接回原会话，不重复执行首次进入时的“新建”或“选择”策略。浏览首页目录也不会替换正在运行的会话。

在同一会话内切换论文时，消息界面保持原状，正在生成的回答继续更新。切换到其他会话时，原会话只是不再显示，任务仍在后台生成；另一会话可以继续提问，返回原会话即可看到最新内容。每条生成任务使用提交问题时的论文材料和页码，切换阅读文件不会改变这条回答的来源。

选择按文件夹共享时，同文件夹内的论文可以延续同一段对话；位于 `papers/` 根目录的未分组文件也作为同一个公共文件夹共享会话。按论文独立模式下，各文件仍保留各自的会话。

跨文件提问时可写目标文件名和页码，例如“讲解模电教材第 278 页”；不必先在屏幕上打开教材。程序只读取目标页面，扫描页会直接提供页图。同名或多个版本请写完整路径。比较多份文件时可以分别写页码；“下一页”等追问沿用刚才的资料，“当前页”指屏幕正在显示的文件。页码默认按 PDF 页面序号定位，印刷页码与 PDF 页码有偏移时仍需根据页面内容核对。

切换会话只收起原任务；点击停止才停止生成，迟到的内容不会继续写入。重新生成会替换原回答及其对话历史；删除或清空后，其他窗口的旧保存不会恢复已删除内容。

“清空当前会话”不会清除论文译文。问答与译文分别保存，输入草稿和未完成翻译任务也会保存以便恢复。跨窗口使用同一会话时，已完成消息会同步；独立会话可以分别讨论。

回答中的公式、表格和代码可直接阅读。引用提供核对入口；若模型没有提供足够依据，请回原文确认，尤其是数字、结论和参考文献。

## 查看与管理记忆

打开 **设置 → 记忆**，或按 `Ctrl+Shift+M`。已保存的称呼、偏好和学习记录以卡片显示，并标明全局、当前论文或当前会话的范围；没有打开会话时也可查看和管理全局记忆。记忆入口集中在设置中。

例如发送“记下来，我叫 Cyan”后，成功保存的称呼会出现在这里。卡片直接显示实际保存的记录，编辑与删除也会更新后续回答使用的记忆；刷新后保留修改。保存失败会明确显示，可重试，不以助手口头承诺作为保存依据。

打开会话后可以手动添加一条会话记忆，并按笔记、标签、引用或问题分类。下方的“个人背景与偏好”用于补充希望长期使用的背景和回答习惯，填写后点击设置底部的“保存”。这些内容用于调整称呼和讲解方式，不作为论文事实的依据。

## 外观与舒适度

设置中提供透光、米宣、深色三种主题，共用同一套控件与布局。

透光默认采用明亮、接近中性的背景，纸面透明度 16%、界面透明度 100%、磨砂程度 48px、纸面圆角 28px。“背景色调”从中性白调到暖白，默认 1%；背景亮度默认 92%，两者分别调节。PDF 用柔和外阴影和细边高光呈现悬浮感：“PDF 悬浮强度”与“纸面边缘高光”默认均为 100%，可独立调节。阅读区只给纸面圆角，首页只给主内容圆角，侧栏保持平直。

在 **设置 → 阅读外观 → 译文卡片材质** 选择液态玻璃或磨砂玻璃。卡片通透度可在 15%–85% 之间调节，雾化程度可在 0–28px 之间调节；液态玻璃另有 0%–100% 的边缘折射滑杆。液态默认通透度 35%、雾化 11.4px、边缘折射 99%；磨砂默认通透度 71%、雾化 9.4px。默认值不是固定值，两种材质分别记住调整结果，切换后自动恢复。

阅读字号默认 17px、行高 1.72、代码字号 12px、内容列宽 916px；界面字号 13.5px、控件大小 100%。首页缩放默认 140%，左右侧栏默认宽度分别为 241px 和 436px。已有自定义布局继续使用保存的参数。

参数即时生效并自动保存。外观效果只改变背景和边缘，不降低卡片文字清晰度，也不改变 PDF 正文像素、缩放或阅读位置。升级时只迁移旧默认值，保留已自定义的参数。

背景亮度范围为 92%–100%，旧版低于下限的值会自动抬高。输入框使用更清晰的细亮边和外阴影，聚焦时加强；深色主题继续保留深色阅读底色。

| 想调整的效果 | 设置方向 |
| --- | --- |
| 纸面更通透或更实 | 纸面透明度、界面透明度 |
| 背景太模糊 | 磨砂程度 |
| 纸面悬浮感太弱或太强 | PDF 悬浮强度 |
| 纸面边缘太亮 | 纸面边缘高光 |
| 卡片需要更透或更模糊 | 译文卡片材质下的通透度、雾化程度 |
| 想增强卡片的液态边缘 | 选择液态玻璃，再调节边缘折射 |
| 圆角过大 | 纸面圆角 |
| 深色白字太亮 | 正文亮度，默认 95% |
| 深色彩字太刺眼 | 彩色文字鲜艳度，默认 65% |
| 译文或回答太小 | 阅读字号 |

深色模式会调整文字页的正文颜色；浅蓝、浅绿等淡彩色图表底框变为保留原色相的深色，避免浅色文字落在亮底上难以辨认。照片与饱和彩色图形保留原色，纯图片页保持原始白底与直角。重置效果会将外观参数与两种卡片材质的参数恢复默认，保留当前主题、卡片材质、字号和阅读位置。

## 常用快捷键

单键操作在输入框之外生效。

| 快捷键 | 操作 |
| --- | --- |
| `T` / `E` / `Q` | 有选区时：翻译 / 解释 / 加入问答 |
| `R` | 框选截图；译文面板中用于截图翻译 |
| `Ctrl+F` | 全文搜索 |
| `PageUp` / `PageDown` | 上一页 / 下一页，双页模式按行翻动 |
| `Home` / `End` | 第一页 / 最后一页 |
| `0` / `+` / `-` | 适应宽度 / 放大 / 缩小 |
| `Ctrl+加号` / `Ctrl+减号` / `Ctrl+0` | 首页：放大 / 缩小 / 重置首页；阅读中：增大 / 减小 / 重置阅读字号 |
| `F11` / `Esc` | 全屏 / 退出全屏或关闭当前浮层 |
| `Ctrl+Shift+M` | 打开设置中的记忆页 |
| `Enter` / `Shift+Enter` | 在输入框中发送 / 换行 |

## 数据、备份与升级

| 内容 | 安装版默认位置 |
| --- | --- |
| 程序及卸载入口 | `%LOCALAPPDATA%\Programs\prt` |
| 论文与文件夹 | 系统“文档”目录下的 `prt\papers` |
| 模型配置、API Key、笔记、会话、草稿、阅读状态及 WebView2 数据 | `%LOCALAPPDATA%\prt\data` |

“文档”使用 Windows 配置的位置，也适用于其他磁盘或 OneDrive。便携版仍把 `papers/`、`data/` 放在 `prt.exe` 旁。退出所有阅读窗口后，复制论文库和数据目录即可备份；只复制程序不会带走资料。

**从旧便携版转为安装版：** 先退出旧版，在安装向导中选择旧 `prt.exe` 所在文件夹。向导会复制里面的 `papers/` 和 `data/`，包括模型配置、会话及窗口设置，原文件不改动。目标必须为空；已经有资料时不会静默合并或覆盖。源目录仍被使用、目标冲突或复制失败时会明确报错，修正后可重试。切换完成后通过开始菜单使用安装版，旧便携副本仍指向原数据，不会自动同步。

**应用内升级：** prt 默认在启动时自动检查新版本，自动检查间隔至少一天；可在 **设置 → 应用更新** 关闭自动检查，或随时手动检查。发现更新后显示提示，不会直接打断阅读或开始安装。点击提示中的查看入口，或打开上述设置页，查看当前版本。点击 **更新并重启** 后，程序下载更新包并校验 SHA256，保存所有阅读窗口的会话、草稿和阅读状态，全部窗口成功退出后完成更新并重启。安装版与便携版均支持，`data/` 和 `papers/` 中的资料保留。

没有网络、下载失败或校验未通过时，保留当前版本并显示错误，可稍后重试。窗口状态尚未保存成功时不会继续覆盖程序；先处理提示再重试。Node 开发服务显示不支持应用自更新的说明，检查入口不会访问发布服务。

**旧版首次升级与手动升级：** 旧安装版没有应用内更新入口时，下载本次新版 `prt-setup.exe`，退出 prt 后直接覆盖安装，**无需卸载**；之后即可从应用内升级。旧便携版退出后只替换原位置的 `prt.exe`，保留相邻的 `papers/` 和 `data/`。手动覆盖安装一直可用。

**卸载：** 在 Windows“已安装的应用”中卸载 prt，个人论文和数据目录保留，重新安装后可继续使用。

不要把数据目录上传到 GitHub、网盘公开链接或问题附件，它包含 API Key 与个人对话。下载页提供 `SHA256SUMS.txt` 校验文件；当前发行包未进行商业代码签名。

使用 AI 时，相关原文、截图和对话会发送到设置的模型接口。服务只在本机监听，不代表模型请求不会联网。

## 常见问题

**为什么下载版和首页截图不同？**

首页截图标注了拍摄版本，并使用独立演示书架。v1.2.9 更新了初始外观参数，升级后还会保留你的自定义设置，因此观感可能不同。请在 [Releases](https://github.com/975952/prt/releases/latest) 下载新版，版本变化见 [更新记录](../CHANGELOG.md)。

**接口连接失败或没有输出？**

检查接口地址、模型名和密钥是否属于同一服务，以及账户额度和网络状态。图片请求还需要视觉模型支持。模型服务返回的错误可用来区分鉴权失败、限流和超时。

**扫描件为什么不能选字？**

纯图片 PDF 没有文字层。可使用截图翻译或页面图片问答；效果取决于图像质量和模型能力。它不等同于已为整篇文件生成可搜索的 OCR 文本。

**为什么换目录后论文和会话不见了？**

先确认启动的是安装版还是便携版。安装版读取上表中的用户目录；便携版读取程序旁的 `papers/`、`data/`。旧便携资料不会仅因安装程序就自动导入，需在安装向导中明确选择旧目录。不要只复制 EXE 后删除原数据。

**如何反馈问题？**

使用 [问题反馈表单](https://github.com/975952/prt/issues/new/choose)，注明版本、系统、复现步骤、预期和实际结果。截图中请遮住密钥与个人资料；尽量用公开论文或合成 PDF 复现。安全漏洞请使用 [私密报告渠道](../SECURITY.md)。
