# 问答与翻译的输出体验

## 产品目标

用户能在第一屏找到当前问题的答案，需要时核对原文，读懂后回到论文。回答深度随问题与对话变化；译文保留原文的含义和结构；格式在生成过程中与完成后保持稳定。

## 内容约定

- 问答先解决当前问题。简单概念简短解释，推导保留关键条件与步骤；用户说“没懂”时换解释方式，追问只补当前缺口。
- 论文事实、通用知识、教学例子、推断与先前助手输出保持来源身份。右栏引用在历史恢复后仍不能成为 PDF 原文证据。
- 当前材料未找到依据不等于整篇论文没有。模型根据已有材料自行决定继续查阅或回答。
- 编号本身不表示题目独立。普通编号小问使用完整上下文连贯回答；只有用户明确要求题目独立时使用并行作答。
- 翻译不补写未选择或不可见的内容；保留否定、条件、比较、数字、单位、公式和编号。截图不自动追加解释，看不清处明确标注。
- 词语使用当前语境中的译法；句段保持段落；表格保留行列；公式与算法保留符号和步骤。重要术语的原词按需保留。

## 呈现约定

- 结果沿用现有扁平侧栏排版。文本原文默认收起，点“原文对照”展开完整内容，采用阅读字号并随结果区一起滚动；PDF 选区可以定位原文。
- 截图保留缩略图。译文可复制、重新翻译；重新翻译绕过缓存并保留原目标语言。
- 正文可以逐段“加入译文”，在草稿中检查、编辑、排序与移除，最后合并成一份原文、一次请求、一条连续译文。输入框的补充原文放在已加入选段之后；图片另译。不根据脚注或图注关键词删除内容，未选中的内容不进入请求。
- 选段保留论文与页码，完整原文、目标语言及来源随历史保存和重新翻译复用；暂停后放回草稿恢复选段结构并保留新输入。合并后超过 20,000 字时不发送、不清空、不静默截断。
- 缓存区分原文、语言、提示词版本、文档、所在页、附近语境与模型配置。模型密钥不进入缓存键。
- 列表保留嵌套和编号；代码保留缩进；表格异常行仍保留全部内容；公式与代码区域局部横向滚动。
- 流式输出冻结完整段落，在未完成部分持续更新。多题的卡片选择和连续视图在输出完成时保持；流式失败保留已经收到的内容。
- 中文输入法确认候选词不触发发送。
- 问答与译文按论文分别保存当前窗口内的文字和图片草稿；切面板、切论文再返回时恢复各自输入。问答失败回填原问答草稿，用户已写的新问题不被覆盖。
- 输入框一次提交的文字和多张截图组成一批翻译，按原顺序执行，固定提交时的论文与目标语言。停止、失败或切论文会暂停整批；“继续未完成”跳过已经成功的项目。
- 暂停批次可“放回草稿”，只回填尚未完成的文字和图片，并保留当前的新输入。批次执行中可以切换面板和编辑下一条草稿，后续图片不会抢回译文面板。
- 草稿按窗口、论文和模式异步保存；同一浏览器资料目录、同一阅读地址下刷新或重新打开可以恢复文字、图片与来源。图片按 Blob 保存，不进入同步 localStorage。恢复读取较慢时，用户的新输入优先，旧存档不能覆盖它。
- 保存失败显示持续提示和重试入口，当前输入仍可编辑；原生窗口关闭会等待草稿保存，未保存时刷新会提示离开风险。首次显示空框不算清空草稿，明确清空和成功发送后不会恢复已提交内容。
- 失败重试按原附件身份消费草稿，保留新输入和新选区；已完成回答的“重新生成”不清除同文新草稿。等待恢复期间切换会话会取消旧请求，截图独立提问重试不会把内部提示词填入输入框。
- 草稿恢复目前按浏览器地址隔离，桌面服务启动端口变化时暂不自动迁移；不同浏览器资料目录也不互通。未完成翻译队列仍仅保留在本次窗口内；已生成译文与原图继续沿用现有历史恢复机制。

## 验收

流程与界面测试使用 `test/artifacts/` 中的独立资料和假模型，不写入用户的 `data/`、`papers/`，不产生真实模型费用。

- `answer-quality.mjs`：来源身份、历史恢复、追问与输出契约。
- `translation-quality.mjs`：原文保真、目标语言、结构与缺失内容规则。
- `render-quality.mjs`：列表、表格、代码、数学、安全链接与合法结构。
- `output-flow.mjs`：逐字符安全边界、多题分段、未闭合公式。
- `reading-output.mjs`：真实浏览器中的原文对照、流式呈现及相关交互。
- `composer-drafts.mjs`、`translation-queue.mjs`：草稿归属、附件去重、整批停止与恢复的状态约束。
- `draft-persistence.mjs`、`draft-recovery.mjs`：异步存储、图片 Blob、原子写入、刷新与同地址重开、清空与发送后的删除、迟到读取和窗口隔离。
- `draft-save-failure.mjs`：真实 IndexedDB 写入失败、事务回滚、首次读取失败、手动重试、刷新保护与关闭钩子的保存顺序；关闭钩子使用模拟 IPC，不终止真实阅读器。
- `retry-draft-safety.mjs`：草稿读取期间换会话、截图独立请求跨保存恢复重试、图片读取期间新输入保护。
- `selection-reading-order.mjs`、`selection-columns.mjs`：几何阅读顺序、双栏/跨页正反向拖选、整页及 Ctrl+A、Ctrl 拼选与复制/翻译的原文和高亮一致性。
- `segmented-translation.mjs`：跳过未选注释、选段编辑排序、单条合并译文、完整原文与页码恢复、超长保护、失败/停止放回、原文/语言重试与窄侧栏操作。
- `composer-workflow.mjs`：实际切面板、切论文、发送失败、部分完成后暂停/续译及窄侧栏任务提示。
- `qa-latency.mjs`、`ai-send-regression.mjs`：模型自主工具决策、流式问答、附件与停止。
- 提示词黄金快照与 manifest 同步更新；交付前重新构建 exe，检查实际内嵌前端并核对文件哈希。

这些测试证明输入、输出、渲染与操作契约。真实回答是否足够准确易懂，需要另用真实阅读样例评估，不能用假模型通过率替代。

## 后续推进顺序

1. 将草稿存储扩展为与浏览器地址无关的应用级恢复，再补充未完成翻译队列的跨重启恢复与原图清理；保留已交付的异步保存和恢复保护。
2. 基于明确段落对应的原译文对照。只有原文与译文具有可靠对应关系时才逐段绑定，不能单凭段落数相同伪造对应。
3. 本篇术语的一致译法及用户纠正入口。当前提示词的可选术语参数只是接口基础，不代表已交付术语库。
4. 指定回答追问、编辑重发与单题重试，保存历史关系和原回答。
5. 建立真实阅读样例的回答质量评审。未获明确范围的持续真实 API 评测不自动运行。

每批先检查当前 Git 状态，保留已有工作；独立测试通过后再构建桌面交付物。只提交明确涉及的源码、文档和测试，不公开发布或推送远端。构建不关闭用户正在使用的阅读器。
