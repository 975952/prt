# Alina 与会话体系

## 身份和设置

主智能体默认叫 **Alina**，中文界面称 **小林**。自定义名称按用户填写的内容显示。

首次进入即可使用默认名字，不再弹出命名浮层。名字、性格、可选性别和交流习惯只在“设置 → 智能体”中修改；页面里的名字是只读标识，不会因为误点进入编辑。保存后同步各个入口与后续交流；未保存的修改可以撤销，关闭设置时会提示是否放弃。

默认性格是“温和、敏锐、表达清楚”，默认习惯是“先直接回答，再按需要展开；不确定时说明，引用论文时给出依据”，性别不预设。这些是可编辑的初始值。名字和人格设定在各窗口、全局对话、论文对话和文件夹对话中共享；修改不改变历史记录和会话归属，下一次模型请求使用新设定。翻译目标、准确性、引用依据和结构化输出仍遵守具体任务要求。

## 入口和界面转换

- 顶部用同一组工作区导航切换 **Library** 与 **Alina／小林**，文献库统一称为 Library。Alina 的侧栏不再重复文献库入口。
- 点击 Alina 进入独立起始页，名字、“今天想读什么？”、输入区和“找论文／继续上次”两张圆角卡片在主区域居中，不放装饰性头像。大屏采用适度限宽；窄屏卡片改为纵向排列，放大后内容较高时可自然滚动。起始页不混入普通会话的空状态或旧论文提示。
- Alina 拥有独立侧栏：新对话、历史会话、最近全局会话，以及底部的“个性与偏好”。最近会话只列标题；新对话回到起始页。窄屏将新对话和历史入口收为顶部一行，设置仍可从应用顶栏进入。
- 起始页可以直接输入；首次发送创建新全局会话。输入框保持同一个 DOM，按可见输入卡的位置和尺寸平滑进入会话底部；清空多行文字后再测量最终布局，消息随之呈现。常规草稿保存状态不挤动布局，生成和发送使用同一动作位置，快速完成也不会突然多出或收掉一行。启用系统“减少动态效果”时不播放动效。
- “继续上次”明确恢复最近的非归档全局会话；“历史会话”只展示全局记录，从起始页进入后返回仍停留在起始页。会话中的新建和历史导航继续使用侧栏，不再在正文上方重复。
- 从阅读器右栏展开时接着当前讨论，保持原会话归属、消息和草稿。进入主智能体的起始页则切到全局范围，两者用途明确。
- 点击“打开论文”，从现有书架选择论文；消息中的论文引用也使用相同的打开路径。
- 点击论文卡片先有按压反馈；论文准备好以后，会话区域、消息和输入区一起收拢到阅读器右侧，侧栏退场，PDF、目录、标签和阅读工具依次平滑出现。右栏展开回完整工作区时播放对应过渡。保留实际消息、输入区域和草稿，不清空聊天再重画。
- 论文打开失败时保留讨论和草稿，可以重试或继续提问。主工作区中的普通问题不会自动把后台打开的旧论文当作本次材料。
- 极窄窗口使用可完整操作的右侧覆盖布局；减少动态效果的系统设置会关闭相应动画。
- 主智能体拥有独立的界面缩放：全屏起始页、历史和对话中使用 Ctrl／⌘ + 加号、减号调整，Ctrl／⌘ + 0 恢复 100%，范围为 70%–160%，重开后保留。它与书架缩放、阅读字号及 PDF 缩放分别保存；进入阅读器右栏恢复正常侧栏尺度，再展开时恢复主智能体的尺度。

Library 主区采用连续的论文缩略图网格，不再重复文件夹分组标题、阅读时间或“继续阅读”信息条。卡片只保留真实 PDF 首页缩略图、标题和阅读状态点；整张卡片可点击，打开时恢复已保存的阅读位置。文件夹筛选留在左侧，“最近阅读”按最近打开时间排序；主区保留搜索与“打开 PDF”。Library 支持独立的 Ctrl／⌘ + 加号、减号与 0 缩放。

## 对话和阅读的呈现

对话布局参考 RoleWorld：用户消息靠右，以简洁圆角气泡呈现；智能体回答靠左展开，统一段落和轮次间距。继续保留 prt 的学术内容风格，公式、表格、代码和文献依据采用原有渲染路径，不把长回答塞进窄气泡。

译文先显示正文；原文、目标语言、复制、重译和删除收在同一底部操作区，复制和重译使用图标。原文默认折叠，可展开核对，也保留回到原文位置的能力。恢复未完成或失败的翻译时只显示一条状态提示，原文仍可用于重试。

PDF 适宽显示保留左右各 10px 的空隙，窄阅读容器各 8px。纸张宽度、两侧边距和阅读位置一并核对，避免一侧贴边或无故占用大块空白。

阅读区采用连续背景，两侧栏不再以实色面板截断纸张阴影。PDF 正文仍限制在阅读容器内，阴影可自然延伸到两侧；分栏处使用淡分界线，悬停、键盘聚焦或拖动时强化拖动提示。

## 打开论文后的三张卡片

三张圆角选择卡在会话内容区内浮现，保持在可见范围，无须滚到消息末尾。卡片使用现有主题、浮窗背景、边框、阴影和留白，有图标、标题与简短说明。

| 选择 | 结果 |
| --- | --- |
| 继续这段对话 | 保留当前讨论及其归属，接着聊所打开的论文 |
| 恢复此前对话 | 选择当前论文或文件夹已有的局部讨论 |
| 开启新对话 | 在当前论文或文件夹范围重新开始 |

卡片不阻挡输入，不强迫选择。直接提交第一个有效问题，默认继续当前讨论，卡片平滑淡出收起。卡片浮层不占正文排版空间，离场不会挤动上下消息、输入框或聊天滚动锚点。消息新增、流式输出和用户自身调整输入框仍遵循原有滚动行为。

直接从书架打开单篇论文时，也可以在问答内容区使用已有的新建／继续入口，保留用户选择的进入策略。

## 会话的三种归属

| 归属 | 历史组织方式 |
| --- | --- |
| 全局 | 在主智能体里统一管理，可伴随多篇论文阅读 |
| 文件夹 | 属于指定文件夹的讨论 |
| 论文 | 属于指定论文的讨论 |

原先“所有文档共用”的记录属于全局历史。主智能体历史只显示全局记录，不自动复制或混入论文、文件夹记录。切换场景不改写设置中原来的会话归属偏好；各段讨论的记录和草稿分别恢复。后台生成任务始终保存到发起时的会话。

打开全屏历史时隐藏当前对话的标题栏和论文选择器，保留侧栏导航；从起始页进入便返回起始页，从对话进入便返回原对话。历史列表每行只保留标题、日期和“更多”；置顶、归档、重命名、更改归属、删除收进该行的更多菜单。菜单可使用键盘打开、上下选择和退出，点击外部、滚动或改变窗口尺寸时会关闭，不将所有操作平铺成重复文字。

## 用户主动转换会话归属

已有内容的当前会话切换菜单，以及历史会话的操作区，提供“更改会话归属”。选择全局、文件夹或论文；局部目标再选择具体位置。提交前显示来源到目标的预览。

- 用户确认“移动会话”后，整段讨论转到目标归属，保留标题、消息、摘要、附件和原论文引用。
- 转换不会与目标已有对话自动合并，也不会覆盖目标已有的未发送草稿。被移动的讨论拥有独立草稿。
- 目标数据与附件就绪后才移出原位置；失败时保留原会话。迟到的旧保存不能重新生成原位置的记录。
- 转换后接着查看目标讨论。文件夹没有论文时，仍可在明确标示该文件夹的完整会话空间继续交流。
- 生成期间暂不允许转换，避免移动中的回答写到错误位置。
- 智能体身份不随会话归属转换改变。

## 描述想找的论文

可以直接告诉小林论文名称、研究主题，或描述记得的方法和内容。小林会整理相关的中英文关键词，核对书架中的标题和正文。文件名只有数字或 arXiv 编号的论文也可以被找到；这依赖可读取的论文内容，不要求你先重命名文件。当前采用标题与全文检索，尚未建立向量索引。

找指定论文时，主要结果按论文自身的标题、首页标题和身份核对；仅在参考文献中提及该论文的其它工作，不作为目标论文卡片。主题检索仍可返回相关工作。简称不能覆盖明确不同的标题或版本。

结果直接显示在当前回答里。纯查找请求只给一句简短确认与论文卡片，不附加摘要、性能指标、阅读建议或没有请求的其它论文。单条回答最多保留四组明确请求的目标；本地与网络结果各最多八篇，先显示前四篇，其余可以展开。

本地论文整张卡片可以点击，也支持 Enter／空格。卡片显示论文标题和必要的作者、年份或文件夹区分信息，不再嵌套“打开第 N 页”按钮，不显示正文碎片和命中页数。点击后打开论文并恢复正常阅读进度，不跳到关键词出现的参考文献页。工作区沿用收拢到右栏的动效，继续保留当前讨论。

小林先查本地。只有本地检索完整完成、没有找到匹配，并且本轮允许联网时，才自动继续查找网络论文。扫描件、损坏文件、读取失败或超时都可能留下未核实的内容；没有匹配时会提供简短说明和可展开的检查范围，不把“暂时没找到”说成“书架里没有”。已找到目标时只保留结果，不再堆叠成功统计、重复查询标题与联网提示。

也可以主动点击“继续联网查找”。如果本轮没有开启联网，按钮旁会说明：点击只为这一次查找联网，不改变你的长期偏好。部分网络来源失败时，已经找到的结果仍可查看；查找停止或失败后，可以重试。

网络检索保留完整标题和研究语境，结合学术来源、文献页面和标题相关性筛选。不能因为一个缩写相同，就把无关领域的博客、百科或站点首页列为论文。没有可信匹配时保持空结果。

网络论文主卡片链接到可核实的来源；只有确实有 PDF 地址时才显示“打开 PDF 链接”和“导入书架”。打开链接交给默认浏览器。导入需要你点击，失败后可以重试；成功后结果变成本地论文卡片，由你决定何时打开，不自动打断正在看的内容。

查找结果随会话保存，恢复历史或更改会话归属后仍可使用。书架选择器继续提供快速按名称和文件夹浏览的入口。

## 保存和本次范围

关闭窗口时会先保存当前内容。如果保存超时，窗口会恢复可操作状态，可以等待后再次关闭或重试；不会一直停在无法操作的关闭状态。

笔记功能本次不扩展。

## 验收场景

独立起始页、默认名直接使用、仅设置内改名和人格持久化、再次进入、入口去重、1920px 大屏和 320px 窄窗口、浅深主题、160% 放大、独立缩放持久化与重置、短行和多行首问逐帧过渡、无 PDF 提问、单篇论文、同文件夹多篇论文、跨文件夹阅读、全局与局部历史隔离、历史更多菜单的鼠标与键盘操作、三种卡片选择、忽略卡片直接提问、卡片离场不挤动正文、草稿恢复、生成中的切换、原文引用跳转、打开失败后继续使用、减少动画、全局／文件夹／论文相互转换、附件和草稿保留、目标冲突、保存或移动失败，以及最终桌面程序内嵌资源与源码一致。

论文查找还覆盖：中英文描述、数字文件名、论文身份与参考文献区分、版本区分、多组结果、整卡点击和键盘打开、恢复阅读进度、本地未完整核实、自动与主动联网、学术相关性过滤、部分网络来源失败、来源及 PDF 链接、导入成功与失败重试、历史恢复与会话移动后继续使用结果，以及关闭保存超时后再次操作。
