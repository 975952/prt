# Alina 与会话体系

## 身份和设置

主智能体默认叫 **Alina**，中文界面称 **小林**。自定义名称按用户填写的内容显示。

第一次打开时显示“定制你的 AI 助手”的一次性提示，可直接跳过；开始定制会打开“设置 → 智能体”。之后仅在设置里编辑，页面名字是只读标识，聊天区和侧栏没有额外的角色编辑入口。

角色模式默认关闭，可以直接正常提问。角色卡包含名字、性格、可选性别、交流习惯、角色背景与关系、示例对话；勾选“启用角色模式”并保存后，后续请求才会附加角色提示词。关闭模式保留卡片，重新开启即可恢复。

展开“让 AI 帮我设定”，通过预先写好的问题逐步聊角色用途、性格、名字与性别、交流习惯和边界。引导阶段不调用模型，逐轮回答即可，也可跳过问题、提前生成或直接粘贴对话；最后点击“生成角色卡”才把完整对话一次性交给当前模型。结果填入下方编辑表单，检查后保存才生效；生成过程不会自动开启模式或修改聊天历史。支持停止和重试，失败不会覆盖已有卡片。手动编辑不需要连接模型；保存和撤销按钮固定在设置底部。

未配置模型密钥时，普通助手聊天和角色卡生成会显示一条固定的正常助手回复，附带“设置 API Key”按钮；点击才跳转到模型设置并定位密钥输入框。问题保留在会话中，配置后可重新生成。明确的密钥认证失败也使用这条引导，不显示报错气泡。

设置每次打开默认居中；切换分类时外层窗口的位置、宽高保持不变，内容只在内部滚动。拖动后切换分类也保持当前位置，再关闭、重开会回到中心；短窗口中保留标题和底部操作。

默认性格是“温和、敏锐、表达清楚”，默认习惯是“先直接回答，再按需要展开；不确定时说明，引用论文时给出依据”，性别不预设。这些是可编辑的初始值。名字和人格设定在各窗口、全局对话、论文对话和文件夹对话中共享；修改不改变历史记录和会话归属，下一次模型请求使用新设定。翻译目标、准确性、引用依据和结构化输出仍遵守具体任务要求。

## 入口和界面转换

- 顶栏右侧、设置按钮之前用同一组工作区导航切换 **Library** 与 **Alina／小林**，文献库统一称为 Library。顶栏保持单行并稍微加厚，原 Windows 入口移除。
- 阅读区是主界面。再次点击当前打开的 Library 或 Alina 按钮，返回最近阅读内容并恢复页码、缩放和页内位置；两者之间临时切换不会覆盖阅读快照。Open paper 与 Chat history 互斥，按钮和历史快捷键都自动收起另一面板。
- 首次点击 Alina 进入独立起始页，名字、“今天想读什么？”、输入区和“找论文／继续上次”两张圆角卡片在主区域居中，不放装饰性头像。临时切到 Library 后返回，会恢复离开前的对话或起始页及草稿；后台生成继续，已完成的回答也直接恢复。大屏采用适度限宽；窄屏卡片改为纵向排列，放大后内容较高时可自然滚动。起始页不混入普通会话的空状态或旧论文提示。
- Alina 拥有独立侧栏：新对话、打开论文、历史会话和最近全局会话。最近会话只列标题；新对话回到起始页。窄屏将主要操作收为顶部一行。侧栏不再单设“个性与偏好”，身份与习惯统一从应用设置修改。
- 侧栏顶部可收起／展开，并记住选择；收起后保留展开、新对话、打开论文和历史的图标入口，为主区让出空间。背景、侧栏、主区和输入卡用透光、边缘高光及阴影区分层次；暗色单独使用墨蓝灰表面，避免浅色渐变在黑底上泛白。
- 起始页可以直接输入；主动“新对话”立即分配独立空会话，首次发送才写入历史列表，不借用上一段对话的草稿。侧栏点击会话直接显示其消息并恢复它自己的未发送草稿，不回填已发送的问题。后台新会话保存后也会更新最近会话列表。输入框保持同一个 DOM，按可见输入卡的位置和尺寸平滑进入会话底部；清空多行文字后再测量最终布局，消息随之呈现。常规草稿保存状态不挤动布局，生成和发送使用同一动作位置，快速完成也不会突然多出或收掉一行。启用系统“减少动态效果”时不播放动效。
- “继续上次”明确恢复最近的非归档全局会话；“历史会话”只展示全局记录，从起始页进入后返回仍停留在起始页。会话中的新建和历史导航继续使用侧栏，不再在正文上方重复。
- 从阅读器右栏展开时接着当前讨论，保持原会话归属、消息和草稿。进入主智能体的起始页则切到全局范围，两者用途明确。
- 点击“打开论文”，从现有书架选择论文；消息中的论文引用也使用相同的打开路径。
- 点击论文卡片先有按压反馈；会话区域、消息和输入区在约 720 毫秒内一起收拢到阅读器右侧，移动前半程保留完整表面，侧栏退场，PDF、目录、标签和阅读工具依次平滑出现。PDF 就绪并恢复真实可见页后才显现；从阅读器展开再返回还会保留页内位置。右栏展开回完整工作区时播放对应过渡。保留实际消息、输入区域和草稿，不清空聊天再重画。
- 论文打开失败时保留讨论和草稿，可以重试或继续提问。主工作区中的普通问题不会自动把后台打开的旧论文当作本次材料。
- 极窄窗口使用可完整操作的右侧覆盖布局；减少动态效果的系统设置会关闭相应动画。
- 主智能体拥有独立的界面缩放：全屏起始页、历史和对话中使用 Ctrl／⌘ + 加号、减号调整，Ctrl／⌘ + 0 恢复 100%，范围为 70%–160%，重开后保留。它与书架缩放、阅读字号及 PDF 缩放分别保存；进入阅读器右栏恢复正常侧栏尺度，再展开时恢复主智能体的尺度。

Library 主区采用连续的论文缩略图网格，不再重复文件夹分组标题、阅读时间或“继续阅读”信息条。卡片只保留真实 PDF 首页缩略图、标题和阅读状态点；整张卡片可点击，打开时恢复已保存的阅读位置。文件夹筛选留在左侧，“最近阅读”按最近打开时间排序；主区保留搜索与“打开 PDF”。Library 支持独立的 Ctrl／⌘ + 加号、减号与 0 缩放。

书架没有 PDF 时显示开始引导，提供“打开第一份 PDF”和“直接与助手聊天”两个入口，并说明可以拖入 PDF、阅读无需 API Key。不显示空的继续阅读卡片、整理按钮和连接模型告警；导入后恢复常规书架。

文件夹标题旁的“+”用于新建文件夹；每个文件夹旁的“…”和右键菜单提供新建子文件夹、重命名、移动及“删除文件夹（保留论文）”。删除先把论文安全移到根目录，再移除空目录；冲突和其他资料会保留原目录，取消即结束。重命名和移动同步标签与阅读路径，文件夹会话迁移失败时仍保留原会话。

Library 的“整理 PDF”提供独立分类预览。点击“AI 分类”后使用当前配置的模型，根据整批文件名、标题、相对目录和分类要求先规划统一目录，再约束各批归类。默认采用较宽泛的一级分类，可选择二级；不会每批另起一套目录，也不套用固定学科清单。分类方案显示各目录篇数，并支持批量改名或合并预览。纯图片 PDF 依据已有标题或文件名判断主题，不做目录 OCR 或全文识别。信息不足或置信度低时需人工确认；手动修改的目标和勾选确认的低置信度建议会保留。分类和停止都不改变当前会话或聊天历史，只有点击“移动选中的文件”后才执行文件移动。具体操作见[使用说明书](使用说明书.md)。

## 对话和阅读的呈现

对话布局参考 RoleWorld：用户消息靠右，以简洁圆角气泡呈现；智能体回答靠左展开，统一段落和轮次间距。继续保留 prt 的学术内容风格，公式、表格、代码和文献依据采用原有渲染路径，不把长回答塞进窄气泡。

完整回答的页码集中在每个小节末尾的轻量来源行，同一论文同一页合并，不在句子中反复插入 `p.1`。已经写在引用块中的原句不再重复追加；来源按钮和原句仍能定位、高亮论文内容，也能用键盘操作。旧会话恢复时同样使用这一排版，原始回答与引用数据保留。

等待模型、查询材料与回退生成共用回答区的一处状态；开始输出后由正文替换，不再同时出现大小两条 Thinking。等待状态不写入答案历史。流式请求以无数据的空闲时长判定超时，持续出字时不会因同一固定时长重新生成。

“ok／好的／明白了”等独立回应沿用当前讨论对象和论文位置，不自动当作词语解释或搜索词；明确询问“OK 是什么意思”仍按词义问题处理。单独问号结合刚才的回答处理困惑或质疑。开启联网表示允许智能体按上下文查找资料，不会在它判断前把每条输入先送去搜索；不支持工具的接口保留必要的检索回退。

译文先显示正文；原文、目标语言、复制、重译和删除收在同一底部操作区，复制和重译使用图标。原文默认折叠，可展开核对，也保留回到原文位置的能力。恢复未完成或失败的翻译时只显示一条状态提示，原文仍可用于重试。

PDF 适宽显示保留左右各 10px 的空隙，窄阅读容器各 8px。纸张宽度、两侧边距和阅读位置一并核对，避免一侧贴边或无故占用大块空白。

阅读区采用连续背景，PDF 正文和纸张阴影限制在阅读视口内，避免放大后覆盖透明聊天侧栏。分栏处使用淡分界线，悬停、键盘聚焦或拖动时强化拖动提示。全屏 Alina 的回答正文与输入框共用内容列，小截图保留自然尺寸并限制预览宽高。

## 打开论文后的三张卡片

三张圆角选择卡在会话内容区内浮现，保持在可见范围，无须滚到消息末尾。卡片使用现有主题、浮窗背景、边框、阴影和留白，有图标、标题与简短说明。

| 选择 | 结果 |
| --- | --- |
| 继续这段对话 | 保留当前讨论及其归属，接着聊所打开的论文 |
| 恢复此前对话 | 选择当前论文或文件夹已有的局部讨论 |
| 开启新对话 | 在当前论文或文件夹范围重新开始 |

卡片不阻挡输入，不强迫选择。直接提交第一个有效问题，默认继续当前讨论，卡片平滑淡出收起。卡片浮层不占正文排版空间，离场不会挤动上下消息、输入框或聊天滚动锚点。消息新增、流式输出和用户自身调整输入框仍遵循原有滚动行为。

直接从书架打开单篇论文时，也可以在问答内容区使用已有的新建／继续入口，保留用户选择的进入策略。

## 会话的三种归属

| 归属 | 历史组织方式 |
| --- | --- |
| 全局 | 在主智能体里统一管理，可伴随多篇论文阅读 |
| 文件夹 | 属于指定文件夹的讨论 |
| 论文 | 属于指定论文的讨论 |

原先“所有文档共用”的记录属于全局历史。主智能体历史只显示全局记录，不自动复制或混入论文、文件夹记录。切换场景不改写设置中原来的会话归属偏好；各段讨论的记录和草稿分别恢复。后台生成任务始终保存到发起时的会话。

打开全屏历史时隐藏当前对话的标题栏，保留侧栏导航及按需打开论文的能力；从起始页进入便返回起始页，从对话进入便返回原对话。历史列表每行只保留标题、日期和“更多”；置顶、归档、重命名、更改归属、删除收进该行的更多菜单。菜单可使用键盘打开、上下选择和退出，点击外部、滚动或改变窗口尺寸时会关闭，不将所有操作平铺成重复文字。

点会话标题打开的快速切换浮层只列标题，置顶与当前会话使用图标标记，不再显示消息数、相对时间或重复范围说明。底部保留简短的历史／新建操作，更改归属放在“更多”内；搜索和键盘切换继续可用。

## 用户主动转换会话归属

已有内容的当前会话切换菜单，以及历史会话的操作区，提供“更改会话归属”。选择全局、文件夹或论文；局部目标再选择具体位置。提交前显示来源到目标的预览。

- 用户确认“移动会话”后，整段讨论转到目标归属，保留标题、消息、摘要、附件和原论文引用。
- 转换不会与目标已有对话自动合并，也不会覆盖目标已有的未发送草稿。被移动的讨论拥有独立草稿。
- 目标数据与附件就绪后才移出原位置；失败时保留原会话。迟到的旧保存不能重新生成原位置的记录。
- 转换后接着查看目标讨论。文件夹没有论文时，仍可在明确标示该文件夹的完整会话空间继续交流。
- 生成期间暂不允许转换，避免移动中的回答写到错误位置。
- 智能体身份不随会话归属转换改变。

## 描述想找的论文

可以直接告诉小林论文名称、研究主题，或描述记得的方法和内容。小林会整理相关的中英文关键词，核对书架中的标题和正文。文件名只有数字或 arXiv 编号的论文也可以被找到；这依赖可读取的论文内容，不要求你先重命名文件。当前采用标题与全文检索，尚未建立向量索引。

找指定论文时，主要结果按论文自身的标题、首页标题和身份核对；仅在参考文献中提及该论文的其它工作，不作为目标论文卡片。主题检索仍可返回相关工作。简称不能覆盖明确不同的标题或版本。

结果直接显示在当前回答里。纯查找请求只给一句简短确认与论文卡片，不附加摘要、性能指标、阅读建议或没有请求的其它论文。单条回答最多保留四组明确请求的目标；本地与网络结果各最多八篇，先显示前四篇，其余可以展开。

本地论文整张卡片可以点击，也支持 Enter／空格。卡片显示论文标题和必要的作者、年份或文件夹区分信息，不再嵌套“打开第 N 页”按钮，不显示正文碎片和命中页数。点击后打开论文并恢复正常阅读进度，不跳到关键词出现的参考文献页。工作区沿用收拢到右栏的动效，继续保留当前讨论。

小林先查本地。只有本地检索完整完成、没有找到匹配，并且本轮允许联网时，才自动继续查找网络论文。扫描件、损坏文件、读取失败或超时都可能留下未核实的内容；没有匹配时会提供简短说明和可展开的检查范围，不把“暂时没找到”说成“书架里没有”。已找到目标时只保留结果，不再堆叠成功统计、重复查询标题与联网提示。

也可以主动点击“继续联网查找”。如果本轮没有开启联网，按钮旁会说明：点击只为这一次查找联网，不改变你的长期偏好。部分网络来源失败时，已经找到的结果仍可查看；查找停止或失败后，可以重试。

网络检索保留完整标题和研究语境，结合学术来源、文献页面和标题相关性筛选。不能因为一个缩写相同，就把无关领域的博客、百科或站点首页列为论文。没有可信匹配时保持空结果。

网络论文主卡片链接到可核实的来源；只有确实有 PDF 地址时才显示“打开 PDF 链接”和“导入书架”。打开链接交给默认浏览器。导入需要你点击，失败后可以重试；成功后结果变成本地论文卡片，由你决定何时打开，不自动打断正在看的内容。

查找结果随会话保存，恢复历史或更改会话归属后仍可使用。书架选择器继续提供快速按名称和文件夹浏览的入口。

## 保存和本次范围

关闭窗口时会先保存当前内容。如果保存超时，窗口会恢复可操作状态，可以等待后再次关闭或重试；不会一直停在无法操作的关闭状态。

笔记功能本次不扩展。
